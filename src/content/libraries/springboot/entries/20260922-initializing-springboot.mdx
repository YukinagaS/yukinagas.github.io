### Getting Started

#### VS Code Extension - Spring Initializr

1. Open VS Code extensions ( <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>X</kbd> ) and install <strong>Spring Initializr Java Support</strong>.
2. Open Command Palette ( <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd> ) and select <strong>Spring Initializr: Create a Gradle Project</strong>.

Upon launching, Spring Initializr will ask a sequence of questions. These notes will use the following configuration:

After dependency selection, VS Code will prompt to select the folder into which it will generate the folder (named after the <strong>Artifact ID</strong>).

<details>
<summary>This is a good time to install the Tasks extension (<strong>Extension ID: </strong>`actboy168.tasks`) to make it easier to launch the backend. Create a `tasks.json` within the `.vscode` directory containing the launch and end commands for a gradle project. Expand this tip for a JSON containing commands for MacOS and Windows.</summary>
  ```json
  {
    "version": "2.0.0",

    // Configure the backend port here
    "options": {
      "cwd": "${workspaceFolder}",
      "env": {
        "SERVER_PORT": "8080"
      }
    },

    "tasks": [
      {
        "label": "$(debug-start) Start Backend",
        "type": "process",

        "osx": {
          "command": "./gradlew",
          "args": ["bootRun"]
        },

        "windows": {
          "command": "cmd.exe",
          "args": ["/d", "/c", "gradlew.bat", "bootRun"]
        },

        "problemMatcher": [],
        "presentation": {
          "panel": "dedicated"
        }
      },
      {
        "label": "$(debug-stop) Stop Backend",
        "type": "process",

        "osx": {
          "command": "/bin/zsh",
          "args": [
            "-c",
            "pids=$(lsof -nP -tiTCP:\"$SERVER_PORT\" -sTCP:LISTEN); if [ -n \"$pids\" ]; then printf '%s\\n' \"$pids\" | xargs kill -TERM; echo \"Backend on port $SERVER_PORT stopped\"; else echo \"Backend is not running on port $SERVER_PORT\"; fi"
          ]
        },

        "windows": {
          "command": "powershell.exe",
          "args": [
            "-NoProfile",
            "-NonInteractive",
            "-Command",
            "$port = [int]$env:SERVER_PORT; $connections = Get-NetTCPConnection -LocalPort $port -State Listen -ErrorAction SilentlyContinue; if ($connections) { $processIds = $connections.OwningProcess | Sort-Object -Unique; $processIds | ForEach-Object { Stop-Process -Id $_ -ErrorAction SilentlyContinue }; Write-Host \"Backend on port $port stopped\" } else { Write-Host \"Backend is not running on port $port\" }"
          ]
        },

        "problemMatcher": [],
        "presentation": {
          "reveal": "always",
          "panel": "shared"
        }
      }
    ]
  }
  ```
</details>
